# 문제 정의 지시 (새 세션)

빌드 세션과 따로 엽니다. 의논한 내용은 PROBLEM.md와 REQUIREMENTS.md에 남고, 빌드 세션은 이 두 파일만 읽습니다. 괄호 안은 과제에 맞게 채웁니다.

## 첫 메시지

```
과제 설명은 (과제 파일), 자료는 (자료 폴더)에 있다.
problem-definition 스킬로 진짜 문제가 뭔지 나와 의논하자. 코드와 설계도는 아직 쓰지 마라.
내가 지금 아는 것: (과제를 읽고 든 생각이나 담당자에게 이미 들은 말. 없으면 "없음")
```

## 확정

```
이 문제로 확정한다. 이유: (내 말로 한 줄)
PROBLEM.md를 확정으로 바꾸고 REQUIREMENTS.md를 모아라.
```
