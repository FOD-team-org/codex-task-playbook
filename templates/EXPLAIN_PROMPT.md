내가 이 프로젝트를 직접 설명할 수 있게 쉬운 말로 정리해 채팅으로만 출력해라. 파일은 만들거나 고치지 마라. 코드와 문서에서 확인한 것만 쓰고, 확인하지 못한 것은 "미확인"이라고 써라.

항목마다 3~5줄, 전체 40줄 안으로 쓴다. 각 항목 끝에 근거가 되는 파일:함수나 명령을 붙인다. 요구사항 번호 같은 내부 번호는 쓰지 않고, 숫자는 소수 첫째 자리까지만 쓴다.

1. 무엇을 풀었나: 누구의 어떤 문제인지, 최우선 목표, 결과 수치
2. 왜 이 방법인가: 고른 방법, 비교한 대안과 같은 조건의 수치, 버린 이유, 남은 한계
3. 값 하나의 흐름: 화면에서 바꾸는 조건 하나가 어떤 파일과 함수를 거쳐 결과로 돌아오는가
4. 저장과 소유: 원본 자료와 계산 결과가 어디에 있고 어느 모듈이 책임지는가
5. 확인한 것과 못 한 것: 실제로 확인한 것 2개(명령과 수치), 가정이나 미확인 2개, 평가자가 확인할 경로
6. 경계: 로그인, 권한, 입력 검증을 어떻게 했고 운영에 올리면 어떤 위험이 있는가
7. 조건이 바뀌면: 자료나 제약이 바뀔 때 다시 확인할 것을 순서대로, AI의 보고가 아닌 판단 근거 2개
8. 문제와 판단: 실제로 발견한 문제 1~2개, 어떻게 드러났는지, AI의 진단 중 받아들인 것과 버린 것
