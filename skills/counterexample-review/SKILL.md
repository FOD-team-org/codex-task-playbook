# 반례 기반 검증

1. REQUIREMENTS.md(없으면 README)의 요구사항을 항목별로 나눈다.
2. 각 항목을 구현한 코드 위치(파일:줄)를 찾는다.
3. 항목마다 경계값, 예외 데이터, 형식 변형(하이픈 유무, 대소문자, 공백, 빈 값)을 검사할 최소 입력을 만든다. 반례 파일은 앱 폴더 밖에 둔다.
4. 실제로 실행해 결과를 확인한다(서버면 HTTP 요청, 함수면 node:test). 실행하지 않은 추정은 결함으로 보고하지 않는다.
5. 앱 코드는 수정하지 않는다. 띄운 서버는 끝나기 전에 종료한다. 브라우저 자동화는 쓰지 않는다.
