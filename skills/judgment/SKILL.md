# 판단대기
서술형 인터뷰는 채팅으로 묻고 `대기: 사용자`로 멈춘다. 유한 선택지·승인·미결 사항은 DECISIONS.md의 `## 판단대기` 절에 등록한다(절이 없으면 만든다).
미룬 인터뷰 문항은 REQUIREMENTS.md의 `미확인 / 가정`에 문항 ID와 함께 적는다.
그 외는 항목마다 다음 필드를 적는다.

```
### A<번호> <제목>
- 배경:
- 선택지: ① 선택1 ② 선택2
- 추천: <추천과 이유>
- 막는 작업: <T>
- 상세: <문서 경로, 없으면 생략>
- 답:
```

작업이 없는 프로젝트 단계는 `막는 작업: -`로 등록하고 답을 기다린다.
답은 번호 하나 또는 자유 서술. 승인 동작은 번호나 승인/진행 토큰이 있어야 한다. 조건부 답은 조건을 함께 보존한다.
모호한 답이나 질문 개정과 맞지 않는 답은 재질문하며 임의 승인하지 않는다. 답을 받으면 `답:`에 원문을 적은 뒤 그대로 적용한다.
답 없이 항목을 완료 처리하지 않는다.

제목 60자·배경 400자·선택지 하나 160자·추천 200자 안으로 짧게 쓴다. 배경은 두 문장 안으로 쓴다. 긴 근거는 프로젝트 문서에 쓰고 `상세:`에 경로로 연결한다(존재하는 파일, DECISIONS.md 자신 제외).
결정된 항목은 DECISIONS.md의 `## 판단기록` 절로 옮기며 질문·답 원문을 함께 보존한다. 판단대기에는 열린 판단만 남긴다.
