# 화면 기준선

디자인 단계는 사람이 정한다. 지시가 없으면 0단계다. REQUIREMENTS.md나 사람의 지시에 단계가 있으면 그 단계를 따른다.

## 0단계: 담백 (기본)
- 화면은 작업 화면부터 시작한다. 히어로 문구·소개 문단·장식용 차트·아이콘 장식·그라데이션·그림자 겹치기·애니메이션은 넣지 않는다.
- 열자마자 기본 조건으로 계산해 결과를 보인다. 날짜를 포함한 조건 입력에는 기본값을 채워 둔다. 빈 화면이나 "조건을 고르고 누르세요"로 시작하지 않는다.
- 결과 바로 위에 요약 줄을 둔다. 요약 줄에는 핵심 숫자 2~4개(처리 건수, 제외 건수, 결과를 판단하는 핵심 지표), 적용한 조건 값, 계산 시각이 들어간다. 숫자는 결과를 판단하는 데 쓰는 것만 고르고, 장식용 숫자는 넣지 않는다. 조건을 바꿔 다시 계산하면 요약 줄 전체가 새 값으로 바뀐다.
- 제외나 경고가 있으면 요약 줄 아래에 이유별 건수를 보이고, 누르면 해당 목록을 볼 수 있게 한다. 계산이 실패하면 이전 결과를 지우고 실패 이유와 다음 행동을 보인다.
- 사람이 아는 이름을 ID와 함께 보인다. 결과는 사람이 판단하는 단위(사람별·날짜별·장소별 등 과제의 묶음)로 묶고, 묶음마다 핵심 값 한 줄을 먼저 보인다. 수십 줄짜리 표 하나에 전부 늘어놓지 않는다.
- 강조색은 하나만 쓰고, 주 동작 버튼 하나에만 쓴다. 상태는 색과 함께 글자 라벨로 표시한다.
- 상태 라벨은 버튼처럼 보이지 않게 한다(테두리 버튼 모양 금지, 옅은 배경의 글자 배지). 누를 수 있는 것만 버튼 모양이다.
- 데이터 표는 table·caption·thead·th scope="col"로 짓는다. 숫자 열은 오른쪽 정렬과 font-variant-numeric: tabular-nums.
- 날짜·시각은 한 줄로 쓴다(white-space: nowrap). Intl.DateTimeFormat·Intl.NumberFormat(ko-KR)로 형식화한다.
- 결과가 0건이면 표 전체 폭 안내 행에 이유와 다음 행동을 적는다. 필터를 바꾸면 "N건 중 M건"을 aria-live="polite"로 알린다.
- 모든 입력에 label을 연결한다. 오류는 해당 필드 옆에 쓰고 aria-describedby로 연결하며, 잘못된 필드에는 aria-invalid를 단다. 제출하면 첫 오류로 포커스를 옮긴다.
- 제출 버튼은 요청 중에만 끄고, 요청 중임을 글자로 보인다.
- 클릭하는 요소는 button이다. outline을 없애면 :focus-visible 스타일을 준다. tabindex는 0보다 크게 쓰지 않는다.
- 빈 값·아주 긴 값에도 표가 깨지지 않게 하고, 넓은 표는 자기 영역 안에서 가로 스크롤한다. 폭 400px에서도 쓸 수 있어야 한다. 확대·축소를 막지 않는다.
- 글꼴은 시스템 글꼴을 쓰고 외부 CDN·웹폰트는 쓰지 않는다.

## 1단계: 정돈 (사람이 디자인 값을 줄 때)
- 0단계 규칙은 그대로 둔다. 기능과 화면 요소는 늘리지 않고 CSS 값만 바꾼다.
- 사람이 준 값(색·글자 크기·행 높이·상단 바)만 CSS 변수로 정의해 적용한다. 값이 없는 항목은 0단계 그대로 둔다.
- 값 예시:
  - 톤: 차분한 사내 업무 도구
  - 색: 배경 #F6F7F9, 표면 #FFFFFF, 글자 #1F2937, 보조 #6B7280, 강조 #1E5EFF(주 버튼·선택 상태만)
  - 상태 배지: 지연=옅은 빨강 배경+진한 빨강 글자, 처리 중=노랑, 완료=초록, 글자 라벨 유지
  - 상단 바: 서비스명 + 기준 시각 한 줄, 높이 56px
  - 표: 머리행 고정, 행 hover 옅은 배경, 행 높이 44px
  - 글자: 제목 20 / 본문 14 / 보조 12px

## 2단계: 브랜드 (사람이 명시할 때만)
- 외부 공개 페이지·랜딩처럼 사람이 브랜드 표현을 요청한 경우에만 쓴다.
- 0단계의 접근성·형식 규칙(label, 오류 연결, 포커스, 표 구조, 숫자 정렬, 400px)은 유지한다. 꾸밈 금지 줄만 풀린다.
- 흔한 AI 화면 문법을 피한다: 보라·남색 그라데이션, 이모지 제목, 반짝이 아이콘, 모든 블록에 같은 둥근 카드와 그림자, 의미 없는 숫자 카드, "~를 혁신하세요" 같은 광고 문구.
