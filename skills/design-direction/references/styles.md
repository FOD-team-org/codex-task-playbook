# 디자인 프리셋

design-direction에서 고른 프리셋의 값이다. 고른 프리셋 하나만 토큰 파일에 옮긴다. 바꾼 색이 있으면 대비를 다시 계산한다.

## 공통 토큰 이름
| 토큰 | 역할 |
|---|---|
| `--color-bg` | 페이지 바탕 |
| `--color-surface` | 패널·카드·사이드바 면 |
| `--color-text` | 본문 글자 |
| `--color-text-muted` | 보조 글자(설명·캡션·열 머리) |
| `--color-border` | 구분선(장식, 대비 기준 없음) |
| `--color-border-strong` | 입력·체크박스 경계(바탕과 면 모두에 3:1 이상) |
| `--color-accent` | 주 버튼 면, 선택 표시 |
| `--color-on-accent` | 주 버튼 글자 |
| `--color-link` | 링크·포커스 테두리 |
| `--color-danger` | 오류·위험 글자 |

- 성공·주의 색이 필요하면 같은 프리셋 안에서 바탕 대비 4.5:1 이상으로 정하고 계산값을 DESIGN.md에 적는다.
- 위험 버튼은 면을 칠하지 않고 `--color-danger` 테두리와 글자로 그린다. 면을 칠해야 하면 그 위 글자색을 정하고 대비를 계산해 DESIGN.md에 적는다.
- 대비 표의 값은 WCAG 2.x 상대 휘도 공식으로 계산했다. 기준: 글자 4.5:1(senior는 7:1), 입력 경계 3:1.
- 표의 "근거"는 수치를 빌린 공개 디자인 시스템이다. 색 값 자체는 KRDS·Carbon 값을 쓴 칸 말고는 이 문서에서 정했다.
