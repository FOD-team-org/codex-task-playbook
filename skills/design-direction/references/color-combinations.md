# 색 조합

프리셋 강조색을 그대로 쓸 수 없을 때 강조색과 보조색을 새로 고르는 방법이다. 바탕·글자·위험 색은 프리셋 값을 유지한다.

## 언제
- 브랜드 주색 하나만 정해져 있을 때.
- 상황 읽기 표의 감성 톤이나 업종이 프리셋 기본 강조색과 맞지 않을 때(예: friendly인데 음식 앱).
- 차트·분류·일러스트처럼 색이 여러 개 필요할 때.

## 색의 네 속성
| 속성 | 뜻 | 화면에서 |
|---|---|---|
| 색상 | 색상환의 각도(0~360) | 브랜드·분위기를 정한다 |
| 명도 | 밝고 어두운 정도 | 위계와 대비를 만든다. 위계는 색상보다 명도 차이로 만든다 |
| 채도 | 선명한 정도 | 높을수록 면적을 작게 쓴다 |
| 온도 | 따뜻함(빨강~노랑)·차가움(초록~파랑~보라) | 화면 전체 분위기를 한쪽으로 모은다 |

- 한 색상에서 명도만 바꾼 단계(옅은 면, 테두리, 기본, 눌림, 짙은 글자)를 먼저 만들고, 상태 표현은 이 단계 안에서 해결한다.

## 조합 유형
| 유형 | 고르는 법 | 느낌 | 화면에서 쓰는 법 | 어울리는 프리셋 |
|---|---|---|---|---|
| 단색 | 색상 하나, 명도·채도만 바꾼다 | 차분, 통일 | 강조와 옅은 면을 같은 색상의 명도 단계로 | saas, dense, trust, senior, editorial |
| 유사색 | 색상환 이웃 2~3개(서로 30° 안팎) | 자연스러움 | 주색 1개 + 분류·보조 면에 이웃 색 | friendly, education, editorial |
| 보색 | 정반대(180°) | 강한 대비, 시선 끌기 | 주색은 넓게, 보색은 구매·알림 같은 한 곳에만 | commerce, media |
| 분할 보색 | 기준색 + 보색 양옆(±30°) | 보색보다 덜 거침 | 주색 1개 + 보조 2개를 배지·차트에 | commerce, education, expressive |
| 삼색 | 120° 간격 3개 | 활기, 놀이 | 하나를 주색, 둘은 채도를 낮춰 작게 | expressive, education(어린이), media |
| 사각 | 90° 간격 4개 | 다채로움, 다루기 어려움 | 차트·분류·일러스트에만. 버튼·입력에는 쓰지 않는다 | expressive |

## 면적 배분
- 중립(바탕·면·글자)이 대부분, 주색이 일부, 보조색이 소량이다. 흔히 60·30·10으로 부른다.
- 업무 도구(saas·dense·trust·senior)는 중립 비중을 더 키우고 주색은 버튼·선택 표시·링크에만 쓴다.
- 위험·성공·주의 같은 의미 색은 조합에 넣지 않는다. 의미 색과 헷갈리지 않게 하는 방법은 순서 5번에 있다.

## 분위기·업종과 색상 계열
| 원하는 분위기·업종 | 색상 계열 | 피할 것 |
|---|---|---|
| 신뢰·금융·공공 | 짙은 파랑, 남색, 차가운 회색 | 형광색, 채도 높은 빨강 면 |
| 차분·수면·명상 | 옅은 파랑, 라벤더, 회청색, 낮은 채도 | 강한 보색 대비 |
| 건강·환경·야외 | 초록, 세이지, 민트, 올리브 | 차가운 회색만으로 된 화면 |
| 음식·식당 | 빨강~주황, 갈색, 크림 | 차가운 회청색 면 위주 |
| 고급·프리미엄 | 검정·차콜·짙은 갈색 바탕에 금색·샴페인 계열 소량, 낮은 채도 | 원색 여러 개 |
| 어린이·놀이 | 명도 높은 노랑·하늘·분홍, 삼색 | 회색 위주 화면 |
| 운동·에너지·게임 | 라임, 선명한 파랑, 마젠타, 어두운 바탕 | 옅은 파스텔만 |
| 창작·포트폴리오 | 보라 계열, 대비 큰 한 쌍 | 화면 전체에 같은 효과 반복 |
| 계절 행사 | 계절 색을 행사 영역에만 기간 한정으로 | 기본 토큰 자체를 바꾸기 |

- 이 연결은 문화권·브랜드마다 다르다. 브랜드 색이 있으면 브랜드가 먼저다.

## 순서
1. 기준색 하나를 정한다. 브랜드 주색, 위 표의 색상 계열, 프리셋 강조색 순서로 찾는다.
2. 조합 유형을 고른 프리셋에 맞춰 고른다(조합 유형 표의 "어울리는 프리셋").
3. 색상각은 HSL에서 돌린다(흔히 쓰는 색상환과 같아 파랑의 보색이 주황이 된다). 명도는 OKLCH 명도(L)로 고친다(눈에 보이는 밝기가 고르다). 어두운 모드 값은 대비를 고치기 전 밝은 모드 후보에서 OKLCH 명도 +0.10~0.15, 채도 ×0.8로 시작해 6번 대비로 맞춘다.
4. 토큰에 놓는다. 주색은 `--color-accent`·`--color-link`(주색 위 글자색은 6번), 보조색은 `--color-accent-2`처럼 새 토큰으로 만들어 배지·차트·일러스트에만 쓴다. 바탕·글자·위험 토큰은 프리셋 값을 둔다.
5. 의미 색과 떼어 놓는다. 보조색이 위험색(밝은·어두운 모드 둘 다)과 HSL 색상각 30° 안이면 30° 밖으로 옮긴다. 판정은 6번 명도 조정을 마친 값으로 하고, 주색의 명도 단계는 주색으로 본다. 옮겨서 유형 모양이 깨지면(분할 보색이 보색과 같아짐 등) 그 보조색을 빼고 남은 색으로 쓴다. 주색이 위험색과 30° 안이면(빨강·주황 브랜드) 주색은 두고, 위험 표시는 색만 쓰지 않고 글자·아이콘을 함께 쓰며 위험 버튼은 테두리형으로 주 버튼과 모양을 다르게 한다.
6. 대비를 계산한다(styles.md 기준과 같음). 모자라면 색상은 두고 명도만 고친다.
   - 주색 위 글자: 브랜드 색이면 색을 지키고 `--color-on-accent`를 흰색과 짙은 글자 중 통과하는 쪽으로 바꾼다. 브랜드 색이 아니면 on-accent는 프리셋 값을 두고 주색 명도를 고친다.
   - 글자로 쓰는 보조색(배지 글자 등)은 바탕 대비 4.5:1, 면으로만 쓰는 보조색(차트 막대·점)은 바탕 대비 3:1.
   - 옅은 면(배경 띠, 선택 행 등)은 면 자체에 기준이 없고, 그 위 글자가 4.5:1이면 된다.
7. design-direction 기록 줄 끝에 `색 조합: <유형> / 기준색: <hex> / 근거: <브랜드 또는 상황 칸>`을 덧붙인다.

## 확인
- 주색이 버튼·선택·링크 말고 넓은 면에 쓰이지 않았다(expressive·media의 대표 구역은 예외).
- 상태와 분류를 색만으로 구분하지 않는다. 글자나 아이콘이 함께 있다.
- 서로 다른 의미에 같은 보조색을 쓰지 않았다.
- 바꾼 색마다 밝은·어두운 모드 대비 값이 기록에 있다.

## 하지 않는 것
- 갤러리·팔레트 모음의 색 조합 값을 그대로 가져오지 않는다. 원리만 쓰고 값은 새로 만든다.
- 조합 색 네다섯 개를 버튼·탭·배지에 고르게 나눠 칠하지 않는다.
- 그라데이션으로 두 색을 섞어 강조를 만들지 않는다.
