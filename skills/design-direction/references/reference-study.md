# 레퍼런스 조사

프리셋 값을 실제 화면으로 보강할 때 쓴다. 네트워크를 쓸 수 없으면 이 문서를 건너뛰고 styles.md 값만 쓴다. 목록의 요금·약관은 2026-11 확인 기준이며 바뀔 수 있으니 쓰기 전에 각 사이트에서 다시 확인한다.

## 기준 뽑는 절차
1. 고른 프리셋의 "보러 갈 곳"과 위 갤러리에서 같은 분야 화면 3~5개를 고른다. 같은 서비스에서 두 장 넘게 고르지 않는다.
2. 화면마다 아래 표 한 줄을 채운다. 값은 눈대중이 아니라 사람이 개발자 도구로 잰 값이나 공개 문서 값을 쓴다. 잴 수 없으면 "미측정"으로 둔다.
3. 3~5줄에서 공통인 원리만 고른다(예: 본문 15~16px, 행 높이 48 안팎, 강조색 한 개). 한 화면에만 있는 특징은 버린다.
4. 고른 원리를 프리셋 값과 비교해 바꿀 칸만 바꾸고, 바꾼 칸과 이유를 DESIGN.md에 한 줄씩 적는다.
5. 바꾼 색은 대비를 다시 계산한다.

| 화면 | 바탕·면 | 강조색 수 | 본문 글꼴·크기 | 제목 크기 | 간격 단계 | 행·버튼 높이 | 모서리 | 눈에 띄는 패턴 |
|---|---|---|---|---|---|---|---|---|
| (서비스, 화면 이름) | | | | | | | | |

## 하지 않는 것
- 화면을 그대로 베끼지 않는다. 로고·사진·일러스트·아이콘 세트·문구·고유 색 조합을 가져오지 않는다.
- 갤러리 화면을 저장소에 넣거나 다시 게시하지 않는다.
- 한 서비스의 값을 통째로 토큰에 옮기지 않는다. 브랜드 정체성을 흉내 내는 결과가 된다.
- 약관을 확인하지 못한 사이트의 화면은 원리 메모에만 쓰고 이미지로 남기지 않는다.
