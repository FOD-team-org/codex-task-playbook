# 스펙 작성
작업 폴더의 SPEC.md로 시작한다. 이미 있으면 기존 문서를 수정한다. 요구사항 원문은 REQUIREMENTS.md에서 가져온다.
수정 작업은 SPEC.md에 `## 수정 <번호>` 절을 더해 쓴다.
기준·제약, 범위 표, 수용 기준, 검증 명령, 금지, 결과 보고 형식을 채운다.
수용 기준은 입력·상황과 관측 가능한 결과를 함께 적는다. 파일 범위와 기존 동작 보존 조건을 적는다.
검증은 바뀐 테스트만 지정하고 전체 스위트는 마지막 검증 단계로 남긴다.
작업 폴더 경로, git·비밀값·외부 발송 금지를 명시한다.
개정할 때만 SPEC.md 머리의 개정 번호(`rev`)를 올린다.

원본에서 제외한 것: 백로그 조회·문서 뼈대 명령, 워크스페이스 모드(레포별 작업 분할), 워크트리 경로, 자식 에이전트 한도.
